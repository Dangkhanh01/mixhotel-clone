# DESIGN TOKENS & VISUAL SPECIFICATION: MIXHOTEL.VN

## 1. Brand Color Palette (Dark Luxury Boutique)

| Token Name | Value | Purpose |
| :--- | :--- | :--- |
| `--background` | `oklch(0.12 0.01 270)` / `#0f0f12` | Dark Primary background across the entire site |
| `--card` | `oklch(0.15 0.01 270)` / `#17171c` | Secondary dark background for room cards, modals, dropdowns |
| `--card-hover` | `oklch(0.18 0.01 270)` / `#1e1e24` | Elevated hover card state |
| `--border` | `oklch(0.22 0.01 270)` / `#25252e` | Subtle borders, inputs, dividers |
| `--gold-primary` | `oklch(0.74 0.07 78)` / `#c5a880` | Primary brand accent: CTA buttons, highlights, hover effects |
| `--gold-bright` | `oklch(0.82 0.08 78)` / `#dfc299` | Hover state for gold buttons, prominent icons |
| `--crimson` | `oklch(0.55 0.22 25)` / `#c92a2a` | Urgent CTAs, "HOT CONCEPT" badges, danger / delete icons |
| `--text-primary` | `#ffffff` | Headings (H1, H2), prominent prices |
| `--text-secondary` | `#a0a0a8` | Body copy, meta tags, timestamps |
| `--text-subtle` | `#707078` | Placeholders, copyright, auxiliary text |

## 2. Typography

- **Headings & Accents:** `Questrial`, sans-serif
  - Round, elegant, luxury feel.
  - Used for Section Titles, Room Names, Hero Display, Stat Numbers.
- **Body & Controls:** `Roboto`, sans-serif
  - Clean, modern, highly legible.
  - Used for body copy, buttons, badges, forms.

## 3. Radii & Shadows

- Card Radius: `12px` (`0.75rem`)
- Button Radius: `8px` (`0.5rem`)
- Badge / Pill Radius: `9999px`
- Modal Radius: `12px`
- Luxury Glow Shadows:
  - Gold Shadow: `0 18px 40px rgba(197, 168, 128, 0.22)`
  - Card Drop Shadow: `0 10px 30px rgba(0, 0, 0, 0.6)`
  - Backdrop Filter: `blur(12px)` with `rgba(0, 0, 0, 0.75)`
